// capabilities

Everything you need.
Nothing you don't.

Built for power users who demand precision, speed, and aesthetic control over their workflow.

⌨
Visual Keyboard Interface
A full interactive QWERTY keyboard rendered in the app. Click any key to assign actions. Modifier combos (Ctrl+Shift+Alt+anything), color-coded indicators, real-time glow feedback. No command lines. No config files. Pure visual control.
QWERTY Layout Modifier Combos Visual Feedback Glow Indicators
🌍
Global Shortcuts
Shortcuts fire system-wide regardless of which app has focus. Works even when the window is hidden in the tray.
OS-Level Hook Always Active
🎨
RGB Theme Engine
4 built-in themes: Cyberpunk, Neon RGB, Minimal Dark, Minimal Light. Switch instantly with zero reload.
Real-time Switch CSS Variables
👤
Profile System
Separate keybind sets for Work, Study, Gaming, or any custom profile. Switch instantly — shortcuts re-register in milliseconds.
⚡
Multi-Action Keys
One key press launches multiple apps AND multiple websites simultaneously, with a configurable delay between each launch.
📊
Live Dashboard
Stat cards, recent trigger history with timestamps, and a quick-launch grid of your most-used shortcuts.
⊟
System Tray
Runs silently in background. Launches at system startup. Never interrupts your workflow.
📦
Import / Export
Portable JSON configs. Share your setup with teammates. Backup before reinstalls. One-click restore.
